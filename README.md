# City Tycoon — v0.1

Первый стабильный фундамент браузерной 3D-игры.

## v0.1
- WebGL 3D-сцена на Babylon.js
- камера с вращением, zoom и перемещением
- игровой мир 100×100
- дороги, разметка, здания, деревья
- освещение и тени
- адаптация к экрану
- базовое сохранение параметров камеры в localStorage

Следующий этап: v0.2 — игрок, управление, столкновения.
