# City Economy

Чистая стартовая архитектура экономического градостроительного симулятора.

## Этап 1
- стабильная точка входа
- GameManager
- единый GameState
- главное меню
- переход меню → игра без перезагрузки
- базовый игровой мир
- вкладки в правом верхнем углу по две в ряд
- локальное сохранение

Следующие системы подключаются поверх этой основы без переписывания ядра.
